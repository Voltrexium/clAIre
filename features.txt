How to use
  Fill the OS columns when you run a check. Replace UNTESTED / leave notes.
  Do not mark WORKED unless you actually saw it succeed on that OS.

Status
  WORKED     Confirmed working
  PARTIAL    Works with caveats (see Notes)
  FAILED     Tried and did not work
  UNTESTED   No confirmation in this repo / this machine
  N/A        Not applicable on that OS

Columns
  Linux-X11   Linux with X11 (README: Cinnamon on X11 is the supported case)
  Linux-WL    Linux Wayland (README: capture is best-effort via xcap + extras)

Notes
  Linux-X11: X11 client list + xcap. Cinnamon/X11 is the documented working case.
  Linux-WL: native Wayland clients are missing from X11 lists. Listing also
  merges AT-SPI, Hyprland, Sway, or niri — only the compositor that is actually

How to test

  Confirm clAIre / panel / wallpaper is not captured.
  Click thumbnail to recapture after switching apps.
  Keep overlay open, focus another app; thumbnail/label should follow.
