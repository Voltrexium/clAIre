Desktop assistant

Ask about what is on your screen.

Press a global hotkey. clAIre captures the screen, or the active window, without stealing focus first, then overlays a small query bar. The screenshot is sent as vision context to the model you configure.

How it works

  1. Hotkey clAIre stays in the tray. The default chord is Ctrl/Cmd+Shift+Space.
  2. Capture It screenshots nothing, the current window, or several windows you pick.
  3. Ask A compact bar appears. Enter sends the question with the screenshot attached.
  4. Answer The bar becomes a resizable chat. Optional web search runs before the model.

Models

OpenAI

API key, a vision model such as gpt-4o, and an optional custom base URL.

Anthropic

API key and a Claude model. The screenshot is included when the model accepts images.

Ollama

A local endpoint, usually http://127.0.0.1:11434, and a vision model such as llava.

Custom

Any OpenAI-compatible /v1/chat/completions server you already run.

Web search is optional: Tavily, Brave, or DuckDuckGo. Results are prepended to the prompt. API keys stay in the OS app-data directory and are never committed.

Keys

Action Result
Global hotkey Capture first, then show the ask bar. Press again to hide.
Enter Send the query with the current screenshot and open the chat window.
Shift+Enter Insert a newline.
Esc Hide to the tray and clear the session.

Setup

Node.js 18+ and Rust 1.77.2+. On Linux, screen capture is most reliable on X11.

bash
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
source "$HOME/.cargo/env"
npm install
npm run tauri dev

Production installers come from npm run tauri build and land in src-tauri/target/release/bundle/. Platform packages are listed in the repository README.

Where settings live

Linux
~/.local/share/com.claire.desktop/
macOS
~/Library/Application Support/com.claire.desktop/
Windows
%APPDATA%\com.claire.desktop\

settings.json holds the provider, hotkey, and capture mode. context/ holds the current thread and the last screenshot. Clear context deletes that folder from the overlay or from Settings.
